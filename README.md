# Amari Digital — Website

Multi-page website for Amari Digital, Nairobi.

## Pages
- `index.html` — Landing page
- `services.html` — All 12 services
- `work.html` — Portfolio & ICT gallery
- `about.html` — About, process, industries, testimonials, FAQ
- `pricing.html` — Digital plans & ICT project pricing
- `contact.html` — Contact form

## Deploy on GitHub Pages

**Step 1 — Create a repository**
1. Go to [github.com](https://github.com) and sign in
2. Click **New repository**
3. Name it `amaridigital.github.io` (or any name)
4. Set to **Public**
5. Click **Create repository**

**Step 2 — Upload the files**
1. Click **Add file → Upload files**
2. Drag and drop all 6 HTML files into the window
3. Write commit message: `Initial deploy`
4. Click **Commit changes**

**Step 3 — Enable GitHub Pages**
1. Go to **Settings → Pages**
2. Under Source, select **Deploy from a branch**
3. Branch: **main** / Folder: **/ (root)**
4. Click **Save**

**Step 4 — Your site is live**

GitHub will give you a URL like:
`https://yourusername.github.io/your-repo-name/`

Takes about 1–2 minutes to go live.

---
**Custom domain (optional)**
1. In Settings → Pages → Custom domain, enter `www.amaridigital.co.ke`
2. At your DNS provider (e.g. Cloudflare), add a CNAME record:
   - Name: `www`
   - Value: `yourusername.github.io`
